# Optional assets for the StackScore portfolio export.

This package ships without binary branding assets so it stays easy to copy.

Recommended portfolio hosting practice:

1. Place a public demo logo at your portfolio site, for example `/branding/demo-logo.svg`.
2. Do not use production client logos, photos of real employees, or confidential diagrams.
3. Keep all visible organization names fictional, as defined in `data/preview-data.ts`.
